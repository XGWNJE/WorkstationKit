# `vmware.vmsg` 词条格式规范

这是逆向所得的文件格式说明，用于读懂、校验或**自行续译** Workstation 的界面文字。实测版本：26H1（build 25688693），参照文件为其自带的 `messages\ja\vmware.vmsg`。

---

## 一、文件格式

- **纯文本**，UTF-8（**无 BOM**），行尾 **CRLF**
- 每行一条，形如：

  ```
  键 = "值"
  ```

- 键名只含 `[A-Za-z0-9_.]`，命名空间实测只有两类：

  | 前缀 | 含义 | 26H1 实测条数（ja） |
  |---|---|---|
  | `button.` | 按钮与菜单项文字 | 380 |
  | `msg.` | 提示、对话框、错误与日志文本 | 6,693 |

- 示例：

  ```
  button.cancel = "取消"
  button.browse = "浏览(_W)..."
  msg.cui.cnx.myComputer = "我的计算机"
  ```

## 二、助记符（快捷键）约定

英文原文用两种前缀标记助记符，翻译时应**保留原拉丁字母**并写成括号形式：

| 英文原文 | 中文写法 | 说明 |
|---|---|---|
| `_Yes` | `是(_Y)` | 下划线形式 |
| `&Apply` | `应用(&A)` | `&` 形式 |
| `Bro_wse...` | `浏览(_W)...` | 助记符在词中，仍移到末尾括号里 |
| `< &Back` | `< 上一步(&B)` | 前缀符号 `<` 保留在开头 |
| `&Next >` | `下一步(&N) >` | 后缀符号 `>` 保留在末尾 |
| `Cancel`（无标记） | `取消` | 原文没有就**不要**自己加 |

保留拉丁字母是关键：中文界面下 Alt 快捷键仍应能用拉丁键盘触发。

## 三、占位符约定

英文原文是 printf 风格，**翻译时应转成位置式**（与厂商 ja 目录的做法一致）：

| 英文原文 | 译文写法 |
|---|---|
| `Connect CD/DVD %d` | `连接 CD/DVD %1$d` |
| `Using Disc Image (%s)` | `正在使用光盘映像(%1$s)` |
| `Cannot open VM: %s, %s` | `无法打开虚拟机: %1$s、%2$s` |

**多占位符必须按出现顺序编号 `%1$`、`%2$`…**，且数量必须与原文一致 —— 数量错配会导致运行时报错或文字错位。校验脚本会检查这一项。

## 四、术语约定（照厂商 ja 目录的口径）

| 英文 | 中文 | 备注 |
|---|---|---|
| `CD/DVD` | `CD/DVD` | 保持拉丁原文 |
| `Tools` | `Tools` | 保持拉丁原文（如 `安装 Tools`） |
| `Floppy` | `软盘` | |
| `Network Adapter` | `网络适配器` | |
| `Parallel Port` / `Serial Port` | `并行端口` / `串行端口` | |
| `Generic SCSI` | `通用 SCSI` | |
| `OK` | `确定` | ja 目录里保留为 `OK`，中文按 Windows 惯例用"确定" |
| `Abort` | `取消` | 与 ja 目录同样归并到"取消" |
| `Snapshot` | `快照` | |
| `Power Off` / `Shut Down` | `关闭电源` / `关闭客户机` | 两者含义不同，不要混用 |

## 五、英文原文在哪里

**安装目录里没有英文版 `vmware.vmsg`** —— 英文原文以 "hashdata" 表**内嵌在二进制**中，格式为：

```
AAA VMware External Hashdata File
@&!*@*@(button.cdrom.retry)Retry
@&!*@*@(button.cdrom.disconnect)Disconnect
@&!*@*@(button.cdrom.ignoreAll)Ignore All
```

即 `@&!*@*@` + `(键)` + 英文值，以 NUL 结尾。用 `tools/extract-english-catalog.py` 扫描安装目录即可提取。

**26H1 实测**（ASCII 标记出现次数）：

| 文件 | 条数 |
|---|---|
| `x64\vmware-vmx.exe` | 2,162 |
| `vmwarecui.dll` | 1,824 |
| `vmwarebase.dll` | 1,636 |
| `vix.dll` | 1,480 |
| `vmcli.exe` | 1,378 |
| `vmwarewui.dll` | 1,252 |
| 其余若干净文件 | 合计约 1,200 |

提取后得到 **5,903 条唯一英文词条**；与 ja 目录的 7,073 条取交集为 **5,831 条** —— 即绝大多数词条都有英文原文可用作底稿。

## 六、另一套资源（不要混淆）

`messages\<locale>\` 下的 `vmui-<locale>.dll` 与 `vmappsdk-<locale>.dll` 是**另一套机制**：它们是纯资源库（`.text` 仅数十字节，内容全在 `.rsrc`），**不含 hashdata 标记，也不含 `.vmsg` 键名**。

实测（ja 目录）：

| 文件 | `.rsrc` 体积 | 可读串数量 | CJK 字符数 | PNG |
|---|---|---|---|---|
| `vmui-ja.dll` | 155,648 | 501 | 25,875 | 27 |
| `vmappsdk-ja.dll` | 13,446,656 | 57,632 | 1,079,530 | 1,017 |

合计 CJK 字符量约为 `.vmsg`（144,727）的 **7.6 倍**。但**实测菜单栏等可见文字来自 `.vmsg`，这两个 DLL 加载失败时界面仍为中文**；且 17.6.4 的中文版 DLL 是 32 位，在 64 位 26H1 上无法加载。因此**续译只需处理 `.vmsg`**。
